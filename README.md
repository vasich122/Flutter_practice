# 📱 Личный кабинет студента

Мобильное приложение для управления академической информацией студента, разработанное на Flutter. Приложение предоставляет удобный интерфейс для отслеживания успеваемости, посещаемости, работы с заявлениями и доступа к научной литературе.

## ✨ Основные возможности

### 🎓 Академические функции
- **Профиль пользователя** - персональная информация и настройки
- **Заявления** - управление подачей и отслеживанием статуса заявлений
- **Академическая информация** - просмотр научной деятельности и достижений
- **Посещаемость** - отслеживание посещаемости занятий по предметам
- **Курсы** - информация о курсах обучения и модулях
- **Оценки** - просмотр оценок с возможностью добавления заметок

### 📚 Помощь студенту
- **Библиотека книг** - поиск книг через OpenLibrary API
  - Поиск по названию, автору, предмету, году издания
  - Просмотр детальной информации о книгах
- **Научные статьи** - доступ к статьям через OpenAlex API
  - Поиск статей по различным критериям
  - Просмотр самых цитируемых статей
  - Поиск по DOI, автору, году публикации

### ⚙️ Дополнительные функции
- **Настройки** - переключение темы (светлая/темная/системная)
- **Оффлайн-режим** - локальное хранение данных с синхронизацией
- **Безопасность** - защищенное хранение конфиденциальных данных

## 🏗️ Архитектура проекта

Приложение построено на принципах **Clean Architecture** с четким разделением на слои:

- **`core/`** - Базовые модели и утилиты
- **`data/`** - Слой данных (API, локальная БД, репозитории)
- **`domain/`** - Бизнес-логика (интерфейсы репозиториев, use cases)
- **`features/`** - UI слой (экраны, cubits, виджеты)
- **`shared/`** - Общие компоненты (темы, DI)

## 🗄️ База данных

Приложение использует **Drift** (бывший Moor) для работы с локальной SQLite базой данных. База данных хранит:

- Заявления (Applications)
- Посещаемость (Attendance)
- Аудитории для занятий (AttendanceClassrooms)
- Курсы и модули (Courses, CourseModules)
- Заметки к модулям курсов (CourseModuleNotes)
- Оценки (Grades)
- Заметки к оценкам (GradeNotes)

Миграции базы данных обрабатываются автоматически при обновлении схемы.

## 🌐 Интеграции с внешними API

### OpenAlex API
Используется для работы с научными статьями:
- Поиск статей
- Получение статей по ID
- Поиск по DOI, автору, году публикации
- Получение самых цитируемых статей

**Базовый URL:** `https://api.openalex.org`

### OpenLibrary API
Используется для поиска книг:
- Поиск по названию
- Поиск по автору, предмету, году издания
- Получение книги по ISBN или ключу

**Базовый URL:** `https://openlibrary.org`

## 🎨 Темы оформления

Приложение поддерживает три режима темы:
- 🌞 Светлая тема
- 🌙 Темная тема
- 🔄 Системная тема (следует настройкам устройства)

Тема сохраняется в SharedPreferences и применяется при запуске приложения.

## 📱 Основные экраны

1. **Экран авторизации** (`/auth`) - вход в систему
2. **Главный экран** (`/main`) - навигационное меню со всеми разделами
3. **Профиль** (`/profile`) - персональная информация пользователя
4. **Заявления** (`/applications`) - список и управление заявлениями
5. **Академическая информация** (`/academic`) - научная деятельность
6. **Посещаемость** (`/attendance`) - статистика посещаемости
7. **Курсы** (`/courses`) - информация о курсах и модулях
8. **Оценки** (`/grades`) - журнал оценок
9. **Помощь студенту** (`/student-help`) - библиотека и статьи
10. **Настройки** (`/settings`) - настройки приложения
